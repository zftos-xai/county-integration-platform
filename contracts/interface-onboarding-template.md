# 单接口工程准入模板

> 复制到获批接口的版本目录后填写；未确认项保留“待确认”，不得据此实现厂商适配。本文记录工程合同证据，接口优先级和跨方进度仍由项目管理台账维护。

## 基本标识

| 项目 | 经双方确认的内容或证据位置 |
|---|---|
| 业务领域 / 接口名称 / 正式编号 / 版本 | 待确认 |
| 县医院系统 / 基层系统 / 调用方向 | 待确认 |
| 启用机构范围和环境 | 待确认 |
| 业务负责人 / 技术负责人 / 验收负责人 | 待确认 |
| 正式接口文件及版本校验值 / 签署依据 | 待确认 |
| 脱敏请求、响应和异常样例的来源与确认人 | 待确认 |
| 测试地址、网络路径、身份机制及凭证交付方式 | 待确认；不在仓库存放凭证值 |

## 合同与安全设计

- [ ] 请求/响应字段、必填、值域、长度、编码、金额及时间单位经双方确认，并保存映射版本。
- [ ] 患者匹配、机构归属、数据用途和服务端权限范围经批准；未批准前默认拒绝。
- [ ] 超时、结果码、查询、撤销、重发和版本兼容规则明确。
- [ ] 写入接口定义幂等键的构成与有效范围；结果未知有只读查询或对账路径。
- [ ] 敏感字段传输、存储、日志、脱敏及留存期限通过医院安全要求。

## 验证与放行

| 场景 | 双方可核对的脱敏证据位置 / 结论 |
|---|---|
| 正常、重复、无权限和参数错误 | 待验证 |
| 超时、断网、目标系统不可用及结果未知 | 待验证 |
| 撤销/再次处理、服务重启及对账差异 | 待验证 |
| 按机构、业务单号和 requestId 串联全流程 | 待验证 |
| SQL Server 迁移、并发、安全及恢复 | 待验证 |
| 代码评审、合同版本、映射和部署制品关联 | 待验证 |

**准入结论：** `CONTRACT_BLOCKED` / 可开发 / 待联调 / 待验收 / 已通过（由实际书面证据决定）。

缺失正式合同、脱敏样例、网络、认证、凭证交付方式或责任人时保持 `CONTRACT_BLOCKED`。Maven 构建通过不构成联调或验收证据。
