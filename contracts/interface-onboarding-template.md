# 单接口工程准入模板

> 复制到获批接口的版本目录后填写；未确认项保留“待确认”，不得据此实现厂商适配。本文记录工程合同证据，接口优先级和跨方进度仍由项目管理台账维护。

## 基本标识

| 项目 | 经双方确认的内容或证据位置 |
|---|---|
| 业务领域 / 接口名称 / 正式编号 / 版本 | 待确认 |
| 源系统 / 目标系统 / 接口提供方 / 调用方 | 待确认；常规基层接口为“基层系统提供、平台调用” |
| 接入类型 | 基层系统WebService / 平台库基础数据视图 / 反向页面或回写 / 其他（待确认） |
| 启用机构范围和环境 | 待确认 |
| 业务负责人 / 技术负责人 / 验收负责人 | 待确认 |
| 正式接口文件及版本校验值 / 签署依据 | 待确认 |
| 脱敏请求、响应和异常样例的来源与确认人 | 待确认 |
| 测试地址、网络路径、身份机制及凭证交付方式 | 待确认；不在仓库存放凭证值 |

## 合同与安全设计

- [ ] 请求/响应字段、必填、值域、长度、编码、金额及时间单位经双方确认，并保存映射版本。
- [ ] 如为平台库基础数据视图，消费方、视图名、最小字段、过滤范围、只读授权、查询频率、单次上限、允许时段、版本兼容和性能基线已确认。
- [ ] 如同步基层基础数据，保存字段、来源标识、版本或更新时间、同步时间、有效状态、全量校准和停用处理已经批准。
- [ ] 患者匹配、机构归属、数据用途和服务端权限范围经批准；未批准前默认拒绝。
- [ ] 超时、结果码、查询、撤销、重发和版本兼容规则明确。
- [ ] 写入接口定义幂等键的构成与有效范围；结果未知有只读查询或对账路径。
- [ ] 按 [平台数据留存边界](../docs/decisions/架构决策.md) 完成数据分类；业务正文默认不留存。
- [ ] 交换记录、审计、对账、告警和备份的留存期限及销毁方式通过医院要求。
- [ ] 如需限时暂存业务正文，已说明必要性、最小字段、加密与密钥、访问授权、起算事件、期限、清理和清理失败告警，并取得书面批准。
- [ ] 日志、错误响应、前端缓存、测试样例、运维附件和问题单不会保存未脱敏报文或完整敏感信息。

## 数据留存配置

| 项目 | 经批准的内容或证据位置 |
|---|---|
| 交换模式 | 即时查询 / 同步写入 / 异步可靠发送 / 其他（待确认） |
| 交换记录字段及留存期限 | 待确认 |
| 是否暂存业务正文 | 否（默认） / 是（须附批准依据） |
| 暂存目的与最小字段范围 | 不适用 / 待确认 |
| 加密、密钥引用、访问角色和机构范围 | 不适用 / 待确认；不得填写密钥值 |
| 留存起算事件、期限和终态后清理期限 | 待确认 |
| 清理任务、失败告警、备份同步清理和审计证据 | 待确认 |
| 正文清理后保留的摘要、业务引用和校验值 | 待确认 |

任一需要暂存业务正文的项目仍为“待确认”时，接口保持 `CONTRACT_BLOCKED`。若不暂存正文，必须确认上游能否按源业务单号重新提供数据，以及该接口是否仍可满足异步发送和服务重启恢复要求。

## 验证与放行

| 场景 | 双方可核对的脱敏证据位置 / 结论 |
|---|---|
| 正常、重复、无权限和参数错误 | 待验证 |
| 超时、断网、目标系统不可用及结果未知 | 待验证 |
| 撤销/再次处理、服务重启及对账差异 | 待验证 |
| 按机构、业务单号和 requestId 串联全流程 | 待验证 |
| SQL Server 迁移、并发、安全及恢复 | 待验证 |
| 正文未超范围留存、到期清理及清理失败告警 | 待验证 |
| 代码评审、合同版本、映射和部署制品关联 | 待验证 |

**准入结论：** `CONTRACT_BLOCKED` / 可开发 / 待联调 / 待验收 / 已通过（由实际书面证据决定）。

缺失正式合同、脱敏样例、网络、认证、凭证交付方式或责任人时保持 `CONTRACT_BLOCKED`。Maven 构建通过不构成联调或验收证据。
