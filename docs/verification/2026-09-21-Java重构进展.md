# Java 重构进展（2026-09-21）

本文记录本轮实际差异与验证边界，不是事前设计记录，也不表示全部 Java 文件已经逐行完成语义评审。工作区包含此前未提交的改动，不能把相对 HEAD 的全部差异归为本轮新增。

## 已落地的调用链调整

- 医院目录、医疗目录、批次、交换记录和管理审计查询直接绑定现有查询对象，删除只用于逐字段复制的请求类型。必填、长度、分页和时间范围等输入规则在 HTTP 入口执行；查询服务不再重复创建 `normalize` 副本。
- 机构、用户、角色、字典、参数和外部系统写入合并无独立语义的 Request/Command。版本字节由请求绑定或 `Func.decodeRowVersion` 解析；Service 保留数据库状态、业务引用和乐观锁冲突判断。
- 目录列表传入获准机构集合，SQL 限域；批次、用户和外部端点按 ID 的读取同样使用范围条件。没有通过删除 SQL 范围条件来“移除 Service 鉴权”。
- 批次执行先在短事务内占用版本，再调用不依赖登录主体的内部同步用例。内部同步只接收批次事实和审计身份，不重复接收批次 ID、机构 ID、版本和完整权限主体。
- HIS 端点能力校验不持有数据库长事务；结果写回比较调用前配置版本，并与审计一起提交。旧结果不能覆盖新配置，失败审计不再记录为成功。
- 通用文本及版本处理复用 `Func`，删除业务类中重复的简单工具封装。参数定义规定的数字、布尔、范围等转换仍属于真实业务规则，不搬进通用工具类。
- 删除医院／医疗目录分类数量的同字段 Model→VO 转换，Mapper 直接返回 API 专用投影；删除只包装校验结果的医疗目录取数结果类型。
- 删除无生产调用方的医疗目录全量缺失失效服务及对应 SQL。当前医疗目录按增量范围同步，空增量不能把其他有效目录失效；医院目录的全量同步语义未改变。已跟踪的删除文件可从 Git 历史恢复。
- 重写本轮涉及的类和方法说明，补充映射表及业务说明，删除空泛继承说明和不准确的审计注释。注释检查不等同于所有注释均已经人工语义验收。

## 关键回归证据

- HTTP 测试：非法分页、版本、日期范围、机构关系 ID、端点地址及参数值在业务调用前返回 400；缺功能权限返回 403。
- 范围 SQL 测试：空机构集合不放开机构数据，按 ID 查询继续限域，用户管理的目标机构在事务中受锁保护。
- MyBatis 绑定测试：不仅生成 SQL，还实际读取 record 派生属性，覆盖时区转换和端点规范地址，避免编译通过但运行时参数取值失败。
- 并发测试：批次占用失败不调用 HIS；端点旧版本结果写回失败时回滚且不追加成功审计。
- 增量测试：医疗目录空范围不触发分类、插入或更新现有目录。
- 工具测试：文本、版本解码和包含数字的驼峰字段名转换。

## 验证与剩余边界

以本轮最后一次 `./tools/verify.sh` 的实际结果为准；它涵盖后端测试、Javadoc、Controller 和包结构检查、Mapper 合同、SQL 静态检查，以及前端类型检查、构建和测试。

以下事项不能据此标为完成：

1. SQL Server 2012 SP4 实例上的真实事务、锁和迁移执行验证。
2. 医院 HIS 的实际取数和能力校验；本地测试中的两个 live probe 缺环境时跳过。
3. 全部 Java 文件逐方法的语义评审与全量 Javadoc 人工验收。当前为全项目自动检查加本轮所列调用链的深入复查，不能将两者混称。
4. 远端 CI、分支保护以及独立评审的实际生效情况。

后续复查应继续沿未验收调用链展开，先判断对象与签名是否必要，再判断边界、失败后果和注释是否准确；不能仅按关键词零命中宣称全量重构结束。
