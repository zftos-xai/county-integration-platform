## 范围和基线

- 只操作此前专门创建的字典类型 `VISTA_ACCEPTANCE_20260929`。开始时该类型停用且 0 个字典项；其他类型未改。
- 测试条目代码：`VISTA_ACCEPTANCE_ITEM_20260929`。仅在该类型下创建，不映射到业务字段。
- 删除前页面确认框显示此确切代码和“后台会先检查业务数据引用”；服务端删除成功提示为“未被业务数据使用，已删除”。

## 写入—刷新—回读

1. 临时启用专用验收类型，页面显示已保存。
2. 创建 `VISTA_ACCEPTANCE_ITEM_20260929`，展示文本“VISTA 验收条目 2026-09-29”、排序 9900、已启用；列表显示 1 项。
3. 编辑展示文本为“VISTA 验收条目已修改 2026-09-29”、排序 9901；保存后列表显示修改后的文本和排序。点击刷新后再次读回相同值。
4. 停用条目并确认；列表显示 0/1 已启用、条目状态“已停用”。刷新后仍为停用。
5. 删除该唯一验收条目。页面提示未被业务数据使用并已删除；类型详情回到 0/0，显示空态。未删除字典类型。
6. 将专用验收类型恢复停用并刷新；最终类型仍停用，条目总数 0。最终可见页面截图已在本轮浏览器工具记录中显示；为避免把管理员页面截图另存为共享文件，本文件保留脱敏读回摘要。

## 判定和源码依据

- 专项结论：条目创建、编辑、停用、引用保护删除和最终刷新读回通过。
- `ConfigurationController` 的创建/编辑/删除都要求 `configuration:write`；`ConfigurationServiceImpl.deleteDictionaryItem` 先调用引用计数，再按 rowversion 删除并写审计。`ConfigurationMapper.xml` 的引用计数查询 SQL Server 外键元数据中的实际引用，删除语句按主键和 rowversion 限定。
- 本次未直接运行 SQL、未删除验收类型、未改其他字典，也未触发外部系统或 HIS。
