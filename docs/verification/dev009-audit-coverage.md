# DEV-009 管理审计覆盖矩阵

## 当前结论

V0500已建立只追加管理审计事件表和按机构范围过滤的只读查询API。登录失败，以及机构、用户、角色、权限、机构范围、参数、字典、外部系统和环境端点的成功变更均已接入。成功事件与业务写入处于同一事务；业务失败不会伪造成功事件。DEV-009代码范围已经收口，仍需完成安全复核和SQL Server 2012 SP4真库验证后才能形成最终验收结论。

## 覆盖矩阵

| 事件类别 | 成功事件 | 失败事件 | 脱敏边界 | 当前状态 |
| --- | --- | --- | --- | --- |
| 登录 | 不记录普通登录成功 | 登录校验失败使用独立事务 | 登录名只保留首字符提示；不保存密码、验证码或会话标识 | 已接入 |
| 参数 | 创建、修改 | 参数校验失败不伪造成功事件 | 不保存参数值 | 已接入 |
| 系统字典 | 类型和字典项创建、修改、启停 | 失败操作不伪造成功事件 | 仅保存对象标识和非敏感动作摘要 | 已接入 |
| 外部系统 | 创建、修改、启停 | 失败操作不伪造成功事件 | 不保存连接地址或凭证引用 | 已接入 |
| 环境端点 | 创建、修改、启停 | 失败操作不伪造成功事件 | 不保存URL、凭证引用或秘密 | 已接入 |
| 机构 | 创建、修改、启停；创建时记录范围授予动作 | 失败操作不伪造成功事件 | 只保存机构代码和非敏感动作摘要 | 已接入 |
| 用户 | 创建、修改、启停、密码重置、角色替换 | 失败操作不伪造成功事件 | 不保存密码、临时密码、密码哈希或角色明细，仅保存动作与数量 | 已接入 |
| 角色与权限 | 角色创建、修改、权限替换 | 失败操作不伪造成功事件 | 只保存角色代码、动作和权限数量，不保存权限明细 | 已接入 |
| 用户机构范围 | 用户创建、主机构变更、机构范围替换 | 失败操作不伪造成功事件 | 只保存用户标识、归属机构快照和机构数量，不保存范围明细 | 已接入 |
