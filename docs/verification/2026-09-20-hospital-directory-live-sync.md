## 机构参数实证

本部署的 `100-008` 返回机构 ID 可作为接口配置身份校验事实，但把该 ID 直接传给 `100-003` 会被 HIS 拒绝。`100-003` 使用平台机构编码时四类目录均成功返回。因此实现按交易保存并使用已验证的机构参数，不再假定一个来源机构 ID 适用于全部交易。
