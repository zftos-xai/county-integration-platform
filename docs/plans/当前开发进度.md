## 二、已交付功能

### 后端与数据库

- 数据库主版本已形成V0100至V1300，ICD-10及HIS调用留痕使用V1200–V1205，交易目录权限使用V1300；目标为SQL Server 2012 SP4兼容级别110。
- 已实现一次性平台初始化、本地账号认证、服务端Session、CSRF、首次改密和登出。
- 已实现机构、用户、角色、功能权限和显式机构数据范围，并保护最后一个启用的平台管理员。
- 已实现参数、系统字典、外部系统和环境服务地址管理；服务地址允许正式接口实际使用的HTTP或HTTPS协议，校验超时边界和凭证引用，不返回凭证内容。

- OpenAPI已同步管理会话、组织与授权、配置、外部系统和审计接口。

### 管理前端

- `/prototype`保留完整合成演示，用于确认信息架构、状态词汇、管理流程和异常恢复交互。
- 原型已覆盖运行总览、基础数据、业务接口、交换记录、告警、审计、参数、字典、外部系统、用户、角色和机构。
- 原型登录支持管理员/运维演示、通用错误提示、首次登录改密、重新登录和退出。
- 正式入口`/login`已接入真实会话API，不使用演示账号或`localStorage`模拟认证。
- 已建立统一API客户端：同源凭据、CSRF、受控错误文案、`requestId`展示和非平台响应识别。

- 正式用户管理页已接入资料、启停、临时密码重置、角色和机构范围API，并隔离基础资料与授权草稿。

2. 本地开发已避开被占用的`8080`，统一使用后端`18080`和Vite`5173`同源代理；生产端口仍由部署环境决定。
3. 生产TLS 1.2证书链、`Secure` Session Cookie、最小权限应用连接和备份恢复尚未验证。
4. 已按现有码与接口规范准备管理列表默认每页条数、管理审计默认查询条数，以及交换方向、交换结果、告警级别三组最小配置；医院扩展参数、外部系统清单和凭证库实施方案仍待确认，不以演示值补齐。
5. DEV-010与B06页面已接入真实API，但浏览器端的完整读写、回读、权限、审计、跨机构拒绝和真实批次详情复验仍未形成业务验收记录。`/prototype`中的合成保存结果不能作为后端数据验收记录。
6. ICD-10真实同步历史核查显示，测试端点曾返回字段越界、重复和同编码冲突；当前策略是保留批次失败/未知状态、不发布不完整结果，待来源方和业务方确认处理规则后重新执行，不能通过手工改表或跳过校验完成验收。
7. 生产TLS、凭证库、最小权限连接、备份恢复和医院目标实例验收仍待DBA/安全负责人确认；开发环境迁移不得替代生产验收。

## 六、基础数据真实状态与下一里程碑

当前代码和数据库链路已覆盖“端点选择 → 批次创建 → 100-007数量核对 → 100-006分页取得 → 字段/重复/冲突校验 → 结果持久化 → 当前目录发布或保留上一成功结果 → 批次详情/HIS调用记录/审计查询”。这证明开发链路可执行，不证明当前测试端点已经产出可发布的完整 ICD-10 目录。

已知真实同步事实：测试端点曾返回西医 36,647 条、中医 2,653 条，但存在字段不满足规则、重复及同类别同编码冲突，批次因此保持 `FAILED` 或 `COMPLETED_WITH_UNKNOWN`，`md_icd10_diagnosis` 未发布不完整数据。该结论来自受控测试端点和开发库回读；不得用手工改表、修改 Flyway 历史或跳过校验替代新批次。

下一里程碑按以下顺序执行：

1. 由环境负责人配置获批的 HIS 测试端点和凭证，并显式开启真实探测；不在文档或前端保存敏感值。
2. 选择一个测试机构，先执行 100-007，再执行 100-006 分页同步，记录批次状态、声明数量、取得数量、拒绝原因和当前目录数量。
3. 从页面复核批次详情的目录结果、HIS调用记录和审计记录；从 `/master-data/directory/icd10` 复核当前有效数据、分类查询和最近批次追溯。
4. 补齐失败、结果未知、无权限、跨机构和重复提交场景；确认失败不覆盖上一成功目录，结果未知不自动重发。
5. 由业务负责人确认字段冲突处理、数量核对和消费方读取结果，形成正式验收记录后，才把 DEV-011/B08 标为业务完成。
