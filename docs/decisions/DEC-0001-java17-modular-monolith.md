# DEC-0001：Java 17 模块化单体基线

- 状态：已采用
- 日期：2026-09-14
- 适用版本：0.1.0

## 背景

项目需在两个月内完成中间接口平台、HIS改造、管理端、嵌入页面、接口联调、私有化部署和交付。核心团队中平台开发2人，系统需要减少部署和跨服务协调成本，同时保持业务边界清楚。

## 决定

后台采用 Java 17、Spring Boot 3.5、MyBatis 和 SQL Server，建设一个可独立部署的单体应用。应用内部按机构、患者、目录、接口配置、交换、对账、告警、权限和审计划分模块。

## 影响

- 一个后台制品统一构建、部署和回退。
- 模块之间通过服务层协作，一个数据库表只由一个模块负责写入。
- 不按页面拆分微服务，不引入分布式事务。
- 后续只有在出现独立扩容、独立发布或独立故障隔离的真实需求时，才评审拆分。

## 恢复方式

如技术基线无法满足医院运行环境，应新增工程决策记录，说明替代方案、数据迁移、兼容验证和恢复计划，不直接修改本记录。
